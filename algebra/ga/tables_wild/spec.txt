# spec for arena/algebra -- the compile-time input of the `gen` rules.
#
# the `wild` entry of the three zero-dimensional systems over a finite field K = GF(p):
#
#  1. "wild" : K[x,y] / (x^2 - 1, y^2 - 1)   p = 2, n = 2
#             ONE reduced point, but NOT etale: x^2 - 1 = (x-1)^2 over F_2,
#             so the Jacobian matrix [[2x,0],[0,2y]] is the zero matrix and
#             Ext^1_A(k,k) has dimension 2.  This is the first table whose
#             cohomology is non-trivial: A = K[C_2 x C_2] is a p-group
#             algebra, so Cohen-Maclane gives P(t) = 1/(1-t), i.e. the Betti
#             numbers b_i = i + 1 for every i >= 0, and the socle is
#             A * N = <(1+x)(1+y)> of dimension 1 (NOT 2).
#
# the two companion entries, generated into tables_cub and tables_fat:
#
#  2. "cub" : K[x] / ((x-1)(x-2)(x-3))     p = 97, n = 1
#             three reduced points; A is semisimple, A = K^3, so the
#             primitive idempotents e_1, e_2, e_3 exist and sum to 1.
#
#  3. "fat" : K[x,y] / (x^2, xy, y^2)       p = 7, n = 2
#             one non-reduced point at the origin; the maximal ideal
#             m = (x,y) has m^2 = 0, edim = 2 < dim_k A = 3, so the local ring
#             is Artinian and NOT regular.
# term syntax inside the `gen` arguments:
#   exponents "e0.e1...:coefficient", terms separated by '|', polynomials by ';'
